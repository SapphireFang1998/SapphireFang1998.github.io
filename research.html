Research & Publications

Research Interests

My research focuses on developing novel machine learning algorithms and their applications in various domains. Specifically, I am interested in:

  • Natural Language Processing and Understanding
  • Computer Vision and Image Analysis
  • Deep Learning for Healthcare Applications
  • Explainable AI and Interpretable Machine Learning
  • Low-resource Machine Learning

Through my research, I aim to bridge the gap between theoretical advancements in machine learning and their practical applications in solving real-world problems.

Publications

2023

Deep Learning Approaches for Natural Language Processing

Doe, J., Smith, A., & Johnson, B.

Journal of Artificial Intelligence Research

PDF Dataset Code Citation

This paper presents a comprehensive survey of deep learning approaches for natural language processing tasks. We review recent advances in transformer-based models and their applications in various NLP tasks such as text classification, named entity recognition, and machine translation.

2022

A Novel Approach to Image Classification Using Convolutional Neural Networks

Doe, J., Williams, C., & Brown, D.

IEEE Transactions on Pattern Analysis and Machine Intelligence

PDF Dataset Code Citation

In this paper, we propose a novel approach to image classification using convolutional neural networks. Our method achieves state-of-the-art performance on several benchmark datasets while requiring fewer parameters and less computational resources compared to existing methods.

Efficient Data Augmentation Techniques for Low-Resource Languages

Doe, J., Garcia, E., & Lee, F.

Conference on Empirical Methods in Natural Language Processing (EMNLP)

PDF Dataset Code Citation

We present a set of efficient data augmentation techniques specifically designed for low-resource languages. Our experiments on 10 different languages show that these techniques can significantly improve the performance of NLP models in low-resource settings.

2021

Towards Explainable AI: A Case Study in Medical Diagnosis

Doe, J., Miller, G., & Wilson, H.

Nature Machine Intelligence

PDF Dataset Code Citation

This paper addresses the challenge of explainability in AI systems used for medical diagnosis. We propose a framework that combines the predictive power of deep learning with interpretable features that can be understood by medical professionals.
